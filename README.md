# Restaurant Data Analysis Project

This repository contains a *Python-based data analysis project* on a Restaurant dataset with over *9000 records*. The project demonstrates data cleaning, exploration, and visualization using popular Python libraries.

## Features
- *Dataset Upload & Loading:* Easily upload CSV files in Google Colab.
- *Exploratory Data Analysis (EDA):* Check dataset shape, column types, missing values, and basic statistics.
- *Data Cleaning:* Handle missing numeric values by filling with median values.
- *Visualization:* Distribution of Aggregate Ratings using Seaborn for insights into customer satisfaction.
- *Cleaned Dataset:* Save the cleaned dataset for further analysis or modeling.

## Tools & Libraries
- Python 3.x
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Outcome
- Understand the distribution of restaurant ratings.
- Learn basic data cleaning and visualization techniques.
- Prepare the dataset for further machine learning tasks if needed.
